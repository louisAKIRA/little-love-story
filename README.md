# Little Flower Field ♡

มินิเกมให้กำลังใจแบบ Pixel Art ผู้รับสร้างตัวละครของตัวเอง เลือกเพื่อนสี่ขา แล้วรับข้อความให้กำลังใจในทุ่งดอกไม้

## วิธีเล่น (3 ขั้น)
1. **แต่งตัวละคร** เลือกสีผิว ทรงผม สีผม แล้วแต่งตัวได้ 2 แบบ: กดลุคสำเร็จรูป 8 ชุดที่ออกแบบจากชุดจริงของหวาน หรือเลือกเสื้อผ้าทีละชิ้น 29 ชิ้นใน 5 หมวด (เดรส เสื้อ กางเกง/กระโปรง เสื้อคลุม รองเท้า) และเครื่องประดับ 21 ชิ้นใน 6 หมวด มีปุ่มสุ่ม
2. **เลือกเพื่อนซี้** แมวหรือหมา ตั้งชื่อน้อง เลือกสีขน และเครื่องประดับ 8 ชิ้นใน 3 หมวด (บนหัว ใบหน้า คอ) จิ้มน้องได้ น้องจะกระโดดและพูดกวน ๆ
3. **ทุ่งดอกไม้** ตัวละครกับน้องยืนด้วยกัน โยนขนมให้น้องได้ เลือกอารมณ์วันนี้ แล้วรับข้อความที่เข้ากับอารมณ์นั้น กดบันทึกเป็นรูปขนาดสตอรี่ได้

- ข้อความแรกเปลี่ยนไปทุกวัน (ข้อความประจำวัน)
- จิ้มน้องครบตามจำนวนที่ตั้งไว้ น้องจะพูดประโยคพิเศษ
- ตั้งแต่ 3 ทุ่มถึงตี 5 ฉากจะเป็นกลางคืนมีดาว และน้องจะทักว่าทำไมยังไม่นอน ลองดูตอนกลางวันได้ที่ http://localhost:3000/?night=1
- มีปุ่มเพลง 8-bit มุมขวาล่าง เริ่มแบบปิดไว้เสมอ
- ตัวละครกะพริบตา น้องกระดิกหาง และหลับตาพริ้มตอนกินขนม
- เลือกฉากหลังได้ 4 แบบในหน้าสุดท้าย: ทุ่งดอกไม้ ชายหาด คาเฟ่ ห้องนอน (รูปสตอรี่เปลี่ยนตามฉาก)
- ฉากเปลี่ยนเองตามเทศกาล เช่น คริสต์มาสมีหิมะตกและน้องใส่หมวกซานต้า ลองดูได้ที่ http://localhost:3000/?festival=christmas
- เว็บจำตัวละคร ชื่อน้อง จำนวนจิ้ม และจำนวนวันที่แวะมาไว้ในเครื่อง เปิดครั้งหน้าจะเข้าทุ่งดอกไม้ทันที
- จดหมายลับ ปลดล็อกเมื่อจิ้มน้องครบ 100 ที หรือแวะมาครบ 7 วัน
- ส่งลิงก์ใน LINE จะมีรูปพรีวิวพร้อมชื่อ (ทำใหม่อัตโนมัติทุกครั้งที่ deploy)

## Run locally
ต้องใช้ Node.js 20.9 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## แก้ข้อความ
ข้อความทั้งหมดอยู่ที่ `src/config/messages.ts`
- `recipientName` = ชื่อผู้รับ ใส่ `{name}` ในข้อความไหนก็ได้ ระบบจะแทนด้วยชื่อนี้ให้ (ถ้าปล่อยว่างจะใช้คำว่า "เธอ")
- ใส่ `{pet}` ได้ด้วย จะกลายเป็นชื่อน้องหมาแมวที่ตั้งไว้ในเกม
- `encouragements` = ข้อความให้กำลังใจทั่วไป (ใช้ตอนยังไม่เลือกอารมณ์)
- `moods` = อารมณ์ 4 แบบ แต่ละแบบมีข้อความของตัวเอง
- `petDefaultNames` = ชื่อน้องตอนเริ่มต้น
- `petTapLines` = คำพูดตอนจิ้มน้อง แยกแมวกับหมา
- `petTreats` / `petTreatLines` = ขนมของน้องและคำพูดตอนกิน
- `tapMilestones` = จิ้มครบกี่ทีแล้วน้องพูดอะไร
- `nightMode` = ช่วงเวลากลางคืนและคำทักของน้อง
- `secretLetter` = เงื่อนไขปลดล็อกและเนื้อหาจดหมายลับ
- `copy.shareTitle` / `shareDescription` / `shareButton` = ชื่อ คำอธิบาย และปุ่มในรูปพรีวิวตอนส่งลิงก์
- `copy` = หัวข้อ ปุ่ม ชื่อขั้นตอน และข้อความอื่น ๆ บนหน้าเว็บ

## แก้เทศกาลและฉาก
- `src/config/festivals.ts` ช่วงวันที่ของแต่ละเทศกาล ข้อความทักทาย ของที่ลอยในฉาก และหมวกเทศกาลของน้อง
  - ใส่วันเกิดของหวานได้ที่ `birthday` (รูปแบบ "เดือน-วัน" เช่น "03-21")
  - ลอยกระทงวันไม่ตรงกันทุกปี ต้องแก้วันที่กับ `year` เองเมื่อขึ้นปีใหม่
  - ลองเทศกาลได้ทุกวันด้วย `?festival=<id>` เช่น `christmas`, `newyear`, `valentine`, `songkran`, `halloween`, `loykrathong`, `birthday`
- `src/config/scenes.ts` รายชื่อฉากหลัง ส่วนหน้าตาของฉากอยู่ใน `src/components/Scene.tsx` และ `src/app/globals.css`

## แก้ตัวละคร / สัตว์เลี้ยง
- `src/config/character.ts` สีผิว สีผม ทรงผม เครื่องประดับ (sprite เป็นตาราง 24x34 ตัวอักษร)
- `src/config/clothing.ts` เสื้อผ้าแยกชิ้น แบ่งเป็นหมวด dress / top / bottom / outer / shoes
- `src/config/looks.ts` ลุคสำเร็จรูป แต่ละลุคคือรายการ id ของเสื้อผ้าและเครื่องประดับ เพิ่มลุคใหม่ได้ที่นี่
- `src/config/pets.ts` หมา/แมว สีขน เครื่องประดับน้อง (sprite เป็นตาราง 24x20 ตัวอักษร)

หลักการวาด
- ทุกแถวของ sprite ต้องยาว 24 ตัวอักษรพอดี ความหมายของตัวอักษรอยู่ในคอมเมนต์หัวไฟล์
- เส้นขอบสีเข้มรอบตัวละครถูกวาดให้อัตโนมัติ ไม่ต้องวาดเอง แต่ต้องเว้นขอบตารางไว้ 1 ช่องรอบด้าน
- ตัวพิมพ์ใหญ่คือเงาของสีเดียวกัน เช่น `h` = ผม, `H` = เงาผม ระบบคำนวณเฉดสีให้เองจากสีที่เลือก
- แสงมาจากซ้ายบน: ประกายอยู่ซ้ายบน เงาอยู่ขวาและขอบล่าง
- เฟรมขยับ: `bodyBlinkRows` (ตัวละครหลับตา), `petBlinkRows` และ `petTailRows` (น้องหลับตาและหางอีกท่า) ระบุเฉพาะแถวที่ต่างจากท่าปกติ

กติกาเสื้อผ้า
- ใส่เดรสแล้วเสื้อกับกางเกงจะถูกถอดให้เอง เลือกเสื้อหรือกางเกงแล้วเดรสจะถูกถอด
- ถ้าไม่ได้ใส่เดรส ต้องมีทั้งเสื้อและกางเกงเสมอ ระบบจะใส่ชิ้นเริ่มต้นให้ (แก้ได้ที่หัวไฟล์ `clothing.ts`)

เพิ่มเครื่องประดับ
- เพิ่ม object ใหม่ใน `girlAccessories` หรือ `petAccessories` แล้วใส่ `category` ให้ตรงกับ id ของหมวด
- เพิ่มหมวดใหม่ได้ที่ `girlAccessoryCategories` / `petAccessoryCategories` (ลำดับในนี้คือลำดับแท็บ)
- ลำดับของชิ้นใน array คือลำดับการวาดทับ ชิ้นที่อยู่หลังจะอยู่บนสุด

## Deploy
แบบเชื่อม GitHub: Push ขึ้น GitHub แล้ว Import เข้า Vercel เว็บจะอัปเดตเองทุกครั้งที่ push

แบบไม่เชื่อม GitHub: deploy จากเครื่องตรง ๆ ด้วย Vercel CLI (ต้องรันใหม่ทุกครั้งที่แก้)

```bash
npx vercel login
npx vercel --prod
```

จากนั้นใช้ Public URL ที่ได้ไปสร้าง QR Code

ถ้าเปลี่ยนโดเมน ให้แก้ `siteUrl` ใน `src/config/site.ts` ด้วย รูปพรีวิวใน LINE จะได้ชี้ไปถูกที่
LINE จำรูปพรีวิวของลิงก์ไว้สักพัก ถ้าเคยส่งลิงก์ไปแล้วรูปยังเป็นของเก่า ให้ลองเติม `?v=2` ท้ายลิงก์
