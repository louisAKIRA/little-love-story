# Little Flower Field ♡

มินิเกมให้กำลังใจแบบ Pixel Art ผู้รับสร้างตัวละครของตัวเอง เลือกเพื่อนสี่ขา แล้วรับข้อความให้กำลังใจในทุ่งดอกไม้

## วิธีเล่น (3 ขั้น)
1. **แต่งตัวละคร** เลือกสีผิว 5 สี, ทรงผม 5 ทรง, สีผม 6 สี, เสื้อผ้า 5 ชุด (มีปุ่มสุ่ม)
2. **เลือกเพื่อนซี้** แมวหรือหมา และสีขน 7 สี (มีปุ่มสุ่ม)
3. **ทุ่งดอกไม้ของเธอ** ตัวละครกับสัตว์เลี้ยงยืนด้วยกัน พร้อมข้อความให้กำลังใจที่กดเปลี่ยนได้

## Run locally
ต้องใช้ Node.js 20.9 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## แก้ข้อความ
ข้อความทั้งหมดอยู่ที่ `src/config/messages.ts`
- `recipientName` = ชื่อผู้รับ ใส่ `{name}` ในข้อความไหนก็ได้ ระบบจะแทนด้วยชื่อนี้ให้ (ถ้าปล่อยว่างจะใช้คำว่า "เธอ")
- `encouragements` = ข้อความให้กำลังใจ (ตอนนี้ใส่ตัวอย่างไว้ 8 ข้อความ เพิ่ม/ลบ/แก้ได้)
- `copy` = หัวข้อ ปุ่ม ชื่อขั้นตอน และข้อความอื่น ๆ บนหน้าเว็บ

## แก้ตัวละคร / สัตว์เลี้ยง
- `src/config/character.ts` สีผิว สีผม ทรงผม เสื้อผ้า (sprite เป็นตาราง 16x26 ตัวอักษร)
- `src/config/pets.ts` หมา/แมว และสีขน (sprite เป็นตาราง 16x15 ตัวอักษร)

ทุกแถวของ sprite ต้องยาว 16 ตัวอักษรพอดี ความหมายของตัวอักษรอยู่ในคอมเมนต์หัวไฟล์
