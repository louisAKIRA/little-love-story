# Little Flower Field ♡

มินิเกมให้กำลังใจแบบ Pixel Art ผู้รับสร้างตัวละครของตัวเอง เลือกเพื่อนสี่ขา แล้วรับข้อความให้กำลังใจในทุ่งดอกไม้

## วิธีเล่น (3 ขั้น)
1. **แต่งตัวละคร** เลือกสีผิว ทรงผม สีผม เสื้อผ้า และเครื่องประดับ (หมวก กิ๊บ แว่น ใส่พร้อมกันได้) มีปุ่มสุ่ม
2. **เลือกเพื่อนซี้** แมวหรือหมา ตั้งชื่อน้อง เลือกสีขน และใส่ปลอกคอหรือโบว์ จิ้มน้องได้ น้องจะกระโดดและพูดกวน ๆ
3. **ทุ่งดอกไม้** ตัวละครกับน้องยืนด้วยกัน โยนขนมให้น้องได้ เลือกอารมณ์วันนี้ แล้วรับข้อความที่เข้ากับอารมณ์นั้น กดบันทึกเป็นรูปขนาดสตอรี่ได้

- ข้อความแรกเปลี่ยนไปทุกวัน (ข้อความประจำวัน)
- จิ้มน้องครบตามจำนวนที่ตั้งไว้ น้องจะพูดประโยคพิเศษ
- ตั้งแต่ 3 ทุ่มถึงตี 5 ฉากจะเป็นกลางคืนมีดาว และน้องจะทักว่าทำไมยังไม่นอน ลองดูตอนกลางวันได้ที่ http://localhost:3000/?night=1
- มีปุ่มเพลง 8-bit มุมขวาล่าง เริ่มแบบปิดไว้เสมอ
- เว็บจำตัวละคร ชื่อน้อง จำนวนจิ้ม และจำนวนวันที่แวะมาไว้ในเครื่อง เปิดครั้งหน้าจะเข้าทุ่งดอกไม้ทันที
- จดหมายลับ ปลดล็อกเมื่อจิ้มน้องครบ 100 ที หรือแวะมาครบ 7 วัน
- ส่งลิงก์ใน LINE จะมีรูปพรีวิวพร้อมชื่อ (ทำใหม่อัตโนมัติทุกครั้งที่ deploy)

## Run locally
ต้องใช้ Node.js 20.9 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## แก้ข้อความ
ข้อความทั้งหมดอยู่ที่ `src/config/messages.ts`
- `recipientName` = ชื่อผู้รับ ใส่ `{name}` ในข้อความไหนก็ได้ ระบบจะแทนด้วยชื่อนี้ให้ (ถ้าปล่อยว่างจะใช้คำว่า "เธอ")
- ใส่ `{pet}` ได้ด้วย จะกลายเป็นชื่อน้องหมาแมวที่ตั้งไว้ในเกม
- `encouragements` = ข้อความให้กำลังใจทั่วไป (ใช้ตอนยังไม่เลือกอารมณ์)
- `moods` = อารมณ์ 4 แบบ แต่ละแบบมีข้อความของตัวเอง
- `petDefaultNames` = ชื่อน้องตอนเริ่มต้น
- `petTapLines` = คำพูดตอนจิ้มน้อง แยกแมวกับหมา
- `petTreats` / `petTreatLines` = ขนมของน้องและคำพูดตอนกิน
- `tapMilestones` = จิ้มครบกี่ทีแล้วน้องพูดอะไร
- `nightMode` = ช่วงเวลากลางคืนและคำทักของน้อง
- `secretLetter` = เงื่อนไขปลดล็อกและเนื้อหาจดหมายลับ
- `copy.shareTitle` / `shareDescription` / `shareButton` = ชื่อ คำอธิบาย และปุ่มในรูปพรีวิวตอนส่งลิงก์
- `copy` = หัวข้อ ปุ่ม ชื่อขั้นตอน และข้อความอื่น ๆ บนหน้าเว็บ

## แก้ตัวละคร / สัตว์เลี้ยง
- `src/config/character.ts` สีผิว สีผม ทรงผม เสื้อผ้า เครื่องประดับ (sprite เป็นตาราง 16x26 ตัวอักษร)
- `src/config/pets.ts` หมา/แมว สีขน เครื่องประดับน้อง (sprite เป็นตาราง 16x15 ตัวอักษร)

ทุกแถวของ sprite ต้องยาว 16 ตัวอักษรพอดี ความหมายของตัวอักษรอยู่ในคอมเมนต์หัวไฟล์

## Deploy
แบบเชื่อม GitHub: Push ขึ้น GitHub แล้ว Import เข้า Vercel เว็บจะอัปเดตเองทุกครั้งที่ push

แบบไม่เชื่อม GitHub: deploy จากเครื่องตรง ๆ ด้วย Vercel CLI (ต้องรันใหม่ทุกครั้งที่แก้)

```bash
npx vercel login
npx vercel --prod
```

จากนั้นใช้ Public URL ที่ได้ไปสร้าง QR Code

ถ้าเปลี่ยนโดเมน ให้แก้ `siteUrl` ใน `src/config/site.ts` ด้วย รูปพรีวิวใน LINE จะได้ชี้ไปถูกที่
LINE จำรูปพรีวิวของลิงก์ไว้สักพัก ถ้าเคยส่งลิงก์ไปแล้วรูปยังเป็นของเก่า ให้ลองเติม `?v=2` ท้ายลิงก์
